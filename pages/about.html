What are DevDiaries?

Documenting my journey

A Digital Diary

DevDiaries is a digital diary where I document my journey in web development. Through this site, I hope to demonstrate my learning, and also keep a digital resource for myself to reflect back on my progress throughout the term. I hope that this digital diary will help keep me motivated through seeing the new skills I've learned each week, and inspire others to try web development too!

Site Goals

With DevDiaries, I hope to learn new skills, and experiment with new designs that I can apply to future projects. I also want to create a portfolio piece that showcases my growth as a web developer over time. By the end of the term, I hope to have a polished site that reflects my skills and creativity in web development.

New Tools I've Learned

Through the labs showcased in DevDiaries, I have started using many new tools, including:

  • Visual Studio Code - A code editor for web development, where I code in CSS and HTML
  • GitHub - A platform for website control and collaboration
  • Co-Pilot - An AI assitant that helps me debug my code
